# CircularHub – Final Deliverable

React + TypeScript + Vite frontend for CircularHub.

## Run

1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost address shown by Vite.

## Final changes included

- Required validation for user-facing transaction/request forms.
- User/Seller Name captured for listings.
- Date picker and time picker support.
- Submission confirmation screens with reference numbers.
- Confirmation/invoice generation for Buy, Sell, Repair, Donate, Recycle and Swap submissions.
- Invoice contains the submitted form data and transaction amount where applicable.
- Expanded NGO data with addresses, ratings, descriptions, tags and images.
- Clean pathway cards with no white browser-style boxes.
- CircularHub centre of the lifecycle orbit stays fixed while pathway nodes rotate around it.
